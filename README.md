# Graphene protobuf contracts

Репозиторий содержит публичные protobuf-контракты Graphene и сгенерированный
Go-код. Исходником служат файлы `v1/**/*.proto`; сгенерированные `.pb.go` и
`_grpc.pb.go` вручную не редактируются.

## Подготовка

```sh
make configure
```

Цель устанавливает закреплённые версии генераторов в локальный каталог `bin/`
и приводит Go-модуль в согласованное состояние. Глобальная установка
инструментов не требуется.

## Изменение контракта

1. Изменить соответствующий `.proto` и комментарии к его семантике.
2. Выполнить `make generate`.
3. Проверить совместимость и качество через `make breaking`, `make lint` и
   `make test`.
4. Закоммитить исходный контракт вместе со сгенерированным Go-кодом.

Контракт агента находится в `v1/agent/agent.proto`. Сведения о машине в нём
представлены версионированными типизированными группами; часто меняющиеся
показатели нагрузки относятся к OTEL-метрикам, а не к inventory facts.

## Основные цели

```sh
make help
make generate
make breaking
make lint
make test
```
